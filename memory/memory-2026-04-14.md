## 技术决定

1. **Filter sebagai dropdown bukan input teks**
   - 理由: Nilai category/status/condition terbatas & predefined — dropdown mencegah typo dan lebih cepat dipakai
   - 影响: UX lebih bersih, tidak perlu validasi input

2. **AND logic antar filter**
   - 理由: Use case "E-Can yang On Hand" butuh semua kondisi terpenuhi sekaligus
   - 影响: Hasil makin spesifik sesuai ekspektasi user

3. **Clear button muncul kondisional**
   - 理由: Tidak memenuhi UI dengan tombol yang tidak relevan saat filter kosong
   - 影响: Dideteksi via `hasFilter` di `applySearchFilter` tiap render
