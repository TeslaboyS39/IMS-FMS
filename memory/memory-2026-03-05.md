## 技术决定

1. **Item-name binding rules (不用 category-level)**
   - 理由: FMC 650 vs FMC 150 绑定规则不同，category 无法区分
   - 影响: `ITEM_BINDING_RULES` + `ITEM_TO_CATEGORY` 两张表维护
   - 依赖: autofillCategory() 必须先于 refreshAvailableAssets() 执行

2. **Inline hex styles for badges/bars (不用 Tailwind classes)**
   - 理由: Tailwind CDN 没有所有自定义颜色，新类别需要独立颜色
   - 影响: 颜色集中在 `CHART_COLORS` 常量管理，易维护

3. **Nav tabs: plain text links (不用 pill/button)**
   - 理由: 用户参考图 (Godly.website) 风格 — elegant, clean spacing
   - 影响: active state 仅改 font-weight + color，无背景

## UI 偏好学习 (用户风格)

> 本节记录从今日 UI 迭代中观察到的 Reclaimer 设计偏好，供下次 session 参考

**喜欢:**
- 简洁 elegant — 参考: Godly.website navbar 风格
- Nav links: plain text，**间距宽** (gap-8+)，no pill/box background
- Logo: 小 icon mark (dark square) + wordmark，不要单纯文字
- Stats cards: 白底 + thin left-border accent color，不要 full gradient background
- Chart bars: 每类别独立颜色 + colored dot label，thin bar (h-1.5)
- Action buttons: solid dark (`bg-gray-900`) primary，ghost/text secondary
- Table: subtle hover (gray-50，不要 indigo)，action buttons 用 text (Edit/Log/Del)
- Badge/pill: inline hex tinted background + matching text color，no heavy Tailwind color classes
- Section headers: `text-xs uppercase tracking-widest text-gray-400` + `border-b`
- Modal header: plain white/dark，no gradient
- Spacing: lebih lega — padding, gap lebih besar dari default

**不喜欢:**
- 彩虹渐变 (rainbow gradients) — "terlalu colorful, kurang professional"
- 全背景色 stats cards (from-indigo-500 to-indigo-600 style)
- Emoji 在 button/heading 中 (navbar emoji tabs)
- 字间距太近 / 元素太密集
- Pill-style nav tabs with background fill
- `shadow-xl` / `rounded-3xl` — 太厚重
- `font-black uppercase` heading — 太"vibe coding"

**设计原则总结:**
- 少即是多，留白优先
- 颜色用于信息区分，不用于装饰
- 交互元素要有足够 breathing room
- Professional ≠ boring，但要 intentional
