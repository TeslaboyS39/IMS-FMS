## 技术决定

1. **Library Excel: SheetJS via CDN**
   - 理由: Vanilla JS app, no build step, CDN paling stabil untuk xlsx native
   - 影响: Tambah ~1 HTTP request saat load; tidak ada dependency npm
   - 依赖: cdn.sheetjs.com (online)

2. **Export scope: filtered, bukan paginated**
   - 理由: User ekspektasi export = semua data yg relevan, bukan cuma halaman aktif
   - 影响: Jika search aktif → filename suffix `_filtered_`; jika kosong → semua data
   - 依赖: fungsi `applySearchFilter()` (sudah ada di codebase)
